SENJA SKY COURIER — a sunset island mail plane. Fly a small prop courier across a sunset archipelago: thread 8 glowing rings inside their ideal speed band, drop parcels onto marked island circles, land on short grass strips, and bring her home before the fuel runs out. Three sorties (Ring Run, Parcel Drop, Island Hop), throttle discipline, wind gusts, stall, fuel and damage — all in Three.js, offline, from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and fly with ↑/W ↓/S pitch, ←/A →/D bank, E/Q throttle, SPACE to drop a parcel, C for cockpit view.
